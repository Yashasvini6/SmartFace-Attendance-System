# SmartFace: Automated Attendance System

SmartFace is a real-time automated attendance system that uses face recognition to identify students and automatically record attendance, reducing manual effort and improving accuracy.

## Features
- Real-time webcam-based face detection
- Automatic student recognition
- Attendance logging with duplicate prevention
- Student registration and management
- User-friendly GUI for camera and database control
- Database-backed attendance storage

## Technologies Used
- Python
- OpenCV
- MediaPipe
- MySQL
- Tkinter

## How It Works
1. Students are registered with facial data.
2. Webcam captures faces in real time.
3. Detected faces are matched with stored data.
4. Attendance is automatically recorded.
5. Cooldown logic prevents duplicate entries.

## How to Run
Run the main Python file after installing required libraries.
